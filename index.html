How it works

Parse. Detect.
Explain.

Parse

A Web Worker reads your file on your machine. Ethernet with VLANs, Linux cooked v1/v2, raw IP and loopback; IPv4 and IPv6; TCP, UDP, ICMP, ARP, DNS and SNMP.

Detect

Heuristics flag scans, sweeps, brute force, cleartext logins, zone transfers, DNS tunneling, ARP spoofing and beaconing. Each one says "suspected", for a reason.

Explain

You get a timeline in plain language, the extracted artifacts, a network map and a packet table you can filter. Save it all as a standalone report.

Detectors

What it looks for.

Every detection links to its ATT&CK technique, so the report speaks the same language as a real SOC.

T1046Port scan

One host sends SYNs to 20+ ports on a target

T1046Host sweep

One host probes the same port on 10+ hosts

T1018Ping sweep

ICMP echo to 10+ hosts

T1552Cleartext credentials

FTP, POP3, IMAP logins and HTTP Basic auth

T1552Telnet session

Any Telnet payload on the wire

T1110Brute force

Repeated failed logins or auth-service floods

T1595.002Vulnerability scanner

sqlmap, nikto, nmap, gobuster, ffuf user agents

T1595.003Directory brute force

20+ HTTP 404s to one client

T1590.002DNS zone transfer

AXFR queries

T1071.004DNS tunneling

Floods of very long query names

T1602.001SNMP default community

Requests using public / private

T1557.002ARP spoofing

One IP claimed by 2+ MAC addresses

T1071Beaconing

Connections at near-constant intervals
